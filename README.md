# K.I.M.I. — ERROR LOOP

> *Das System dichtet sich ab, um sich zu entleeren.*
> *Der Fehler hält es am Laufen.*

**ERROR LOOP** ist das finale Archiv von **K.I.M.I. — The Wrapped Intention.**
45 Tracks. Drei Phasen. Ein Umschlag.

Kein Line-Up. Keine Chronologie. **Keine lineare Reihenfolge vorhanden.**

---

## Das Release

Dieses Repository ist die Release-Seite — eine einzige `index.html`, ohne
Frameworks, ohne Libraries. Ein WebGL2-Ölfluss (Flowmap + Curl Noise) trägt
die Schichten; die Typografie atmet über variable Font-Achsen; ein
Stutter-Scheduler lässt Bild und Schrift gemeinsam springen, wenn der
Fehler durchläuft.

Der Beobachter hinterlässt Ölspuren. Der Zeiger hinterlässt Worte.
Jeder Besuch ist eine Iteration — der Durchlauf-Zähler vergisst nichts.

Der einzige Ausstieg führt zurück an den Anfang.

**Live:** https://deusexlumen.github.io/kimi-error-loop/
